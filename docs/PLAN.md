## Как собирать (справка)

```bash
UNITY=/home/user/Unity/Hub/Editor/6000.4.5f1/Editor/Unity
PROJ=/home/user/Downloads/MU/ImmersiveTech_Labs
# пересборка сцен
"$UNITY" -batchmode -nographics -quit -projectPath "$PROJ" -executeMethod LabBuilder.BuildAll -logFile /tmp/build.log
# скриншоты (нужен дисплей/GPU)
DISPLAY=:1 "$UNITY" -batchmode -quit -projectPath "$PROJ" -executeMethod SceneScreenshot.CaptureAll -logFile /tmp/shots.log
```
